Platform in Threes

Character Possession Puzzle • Unreal Engine 5 • Blueprints

Project Overview

Platform in Threes is a puzzle-platformer built in Unreal Engine 5 that centers on a Possession Mechanic. To progress, players must strategically switch control between three distinct characters, each possessing unique physical properties and abilities required to bypass specific environmental obstacles.

Project Highlights

  • Possession System: Developed a character-swapping framework using the "Possess" logic in UE5 to transfer player input between different pawns.
  • Unique Character Classes: Designed three distinct character archetypes with varying jump heights, movement speeds, and weights.
  • Level Interactivity: Created puzzles that require the combined efforts of all three characters, emphasizing teamwork and sequential problem-solving.
  • Camera & UI Management: Implemented a dynamic camera transition system to smooth the visual jump between controlled characters.
  • Blueprint Scripting: Built the entire game logic using Unreal’s Blueprint system, focusing on clean communication between Actors.
